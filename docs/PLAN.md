# pass_kuai — 기획서 (MVP)

중국어 학습 앱. 사진을 찍어 문장을 분석하고, 단어장에 저장해 복습하며,
발음·받아쓰기·단어 학습으로 익히는 앱.

- 플랫폼: Flutter (iOS / Android 동시)
- 목표: 핵심 기능을 빠르게 배포 (MVP), 이후 점진 확장

---

## 1. 확정된 의사결정

| 항목 | 결정 | 이유 |
|------|------|------|
| 문장 분석 엔진 | **LLM Vision API 1회 호출** (OCR+번역+단어분리+병음+성조 통합) | 개별 라이브러리 조립 대비 가장 빠른 MVP, 높은 정확도 |
| 발음 평가 | **녹음 비교 + STT 글자 일치 체크** | 정밀 성조 채점(Azure)은 출시 후로 미룸 |
| 데이터 저장 | **기기 로컬** (로그인 없음) | 백엔드 최소화, 출시 속도 우선 |
| 로컬 DB/ORM | **Drift (SQLite)** | 타입안전 쿼리·마이그레이션, `watch()` 리액티브(Riverpod 궁합), 검색·정렬·`UNIQUE(hanzi)` 중복방지 |
| API 키 보안 | **얇은 서버리스 프록시 1개** | 앱에 키 직접 노출 방지 (악용·과금 폭탄 방지) |

> 추후 확장: 클라우드 동기화(계정), 성조 정밀 채점, 무료 온디바이스 폴백.

## 2. 기능 범위 (MVP IN / OUT)

### IN (이번 출시)
- **A. 카메라 분석**: 사진 촬영/선택 → 문장 추출 → 전체 번역 → 단어별 뜻 → 병음(성모·운모·성조) → TTS 듣기
- **B. 단어장**: 분석 결과의 문장/단어를 저장 → 목록·상세 조회 → 삭제
- **C. 학습 3종**:
  1. 발음 따라하기 — 중국어 문장 보고 발음 → 녹음/STT로 자가 비교
  2. 받아쓰기 — 한국어 문장만 보고 중국어로 입력 → 채점
  3. 단어 학습 — 단어장 기반 카드 학습(뜻↔한자, 병음 확인)

### OUT (다음 단계)
- 로그인 / 클라우드 동기화
- 성조 정밀 채점(피치 분석)
- SRS(간격 반복) 고도화, 통계/스트릭
- 손글씨 인식, 필기 연습

## 3. 기술 아키텍처

```
[Flutter 앱]
  ├─ 카메라/갤러리 (image_picker)
  ├─ 로컬 DB: Drift (SQLite) ─ 단어장/문장/학습기록
  ├─ TTS (flutter_tts, zh-CN)        ← 무료, 온디바이스
  ├─ STT (speech_to_text, zh-CN)     ← 무료, 온디바이스 (발음/받아쓰기 비교)
  └─ HTTP → [프록시]
                 └─ LLM Vision API (이미지 → 분석 JSON)
                 └─ LLM Text API   (문장만 입력 시 분석 / 받아쓰기 채점 보조)
```

- **프록시**: 서버리스 함수 1개(예: Cloudflare Workers 또는 간단 Node). 역할은 API 키 보관 + 요청 전달뿐. 상태 없음.
- 앱은 프록시 URL만 알고, 실제 키는 모름.

## 4. 핵심 계약 — 분석 JSON 스키마

모든 기능이 이 한 가지 응답 형태를 공유한다. (앱·프록시·프롬프트가 합의해야 할 단일 진실)

```json
{
  "sentence": "我想喝一杯咖啡",
  "translation": "나는 커피 한 잔을 마시고 싶다",
  "words": [
    {
      "hanzi": "我",
      "pinyin": "wǒ",
      "initial": "",        // 성모 (없으면 빈 문자열)
      "final": "wo",         // 운모
      "tone": 3,             // 성조 1~4, 경성 0
      "meaning": "나",
      "pos": "대명사"
    }
  ]
}
```

- 사진 입력: 위 전체를 Vision으로 한 번에 생성.
- 텍스트 입력: 동일 스키마를 텍스트 모델로 생성(단어장 수동 추가 등에 재사용).

## 5. 데이터 모델 (로컬)

```
SavedSentence
  id, hanzi, translation, createdAt, sourceImagePath?

SavedWord
  id, hanzi, pinyin, initial, final, tone, meaning, pos,
  createdAt, srsLevel(기본0), nextReviewAt?,
  isFavorite(기본false)
  // 중복 방지: 같은 hanzi가 이미 있으면 새로 만들지 않고 무시(또는 갱신)
  // 검색은 나중에 hanzi/pinyin/meaning LIKE 쿼리로 추가 (지금은 필드만 확보)

StudyLog            // 학습 기록(선택)
  id, type(pron|dictation|word), refId, score, createdAt
```

단어장 추가 시 분석 결과의 word/sentence를 위 테이블로 저장.

## 6. 화면 구조 (IA)

```
하단 탭 3개
├─ 분석(홈)
│   ├─ 헤더 📷 → [사진 찍기 / 갤러리 선택] 시트 ─┐
│   └─ 중국어 직접 입력 → 분석하기            ─┘
│        → [분석 결과 = 문장 리스트]  (中文 + 한국어 번역, 여러 문장 대응)
│             └─ 문장 선택 → [단어별 상세 분석]
│         [분석 결과 = 문장 리스트] 中文 + 번역 (1개여도 리스트로 통일)
│         [단어별 상세] 원문(성조색) + 번역 + 단어 카드(한자/병음/성조/뜻/품사)
│         · ▶ 문장 듣기, ▶ 단어 듣기, ＋단어장 추가(단어/문장 단위)
├─ 단어장
│   └─ 문장 탭 / 단어 탭 → 상세 → 삭제
└─ 학습
    └─ 모드 선택
         · 발음 따라하기 → 문장 표시 → 녹음 → 결과 비교
         · 받아쓰기 → 한국어 표시 → 중국어 입력 → 채점
         · 단어 학습 → 카드 넘기기(뜻↔한자/병음)
```

- 성조 시각화: 성조별 색상(1성 빨강·2성 초록·3성 파랑·4성 보라·경성 회색) — 학습 앱 관습.
