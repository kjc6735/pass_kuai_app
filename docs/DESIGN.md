# pass_kuai — 디자인 시스템 (세이지 & 샌드)

방향: 차분한 정원. 모래빛 배경 위 흰 카드(얇은 테두리), 강조색은 세이지 하나, 한자는 성조 색.
글자는 검정 대신 짙은 올리브. 어두운 면(검정 카드·탭)은 쓰지 않는다.
코드 기준: `lib/theme/app_colors.dart`, `lib/theme/app_theme.dart`, `lib/components/ui.dart`
시안: 캔버스 "pass_kuai 새 디자인 시안" › 시안 후보 › A

## 글꼴
- 한국어·영문: Pretendard (앱에 포함, `assets/fonts`, OFL)
- 한자: 기기의 중국어 간체 글꼴 (iOS PingFang SC, Android Noto Sans CJK SC)
- 굵기(`AppWeights`): 한자 500, 아주 큰 한자 400, 병음 500, 제목·버튼 700, 작은 강조 600

## 모양
- 화면 좌우 패딩 20px, 카드 라운드 18 (큰 카드 24~28)
- 버튼 높이 56, 라운드 16 / 아이콘 버튼 44×44
- 하단 탭: 가운데 떠 있는 좁은 흰 캡슐, 선택한 탭만 세이지 알약(흰 아이콘 + 이름)

## 원칙
1. 한 화면의 주요 동작(세이지 채움 버튼)은 하나.
2. 색만으로 구분하지 않는다: 틀린 음절은 빨간색 + 테두리, 성조 안내는 점 + 이름.
3. 터치 영역은 44px 이상, 글자 대비 4.5:1 이상.
4. 빈 화면에는 "왜 비었는지 + 다음에 할 일"을 같이 보여준다.
