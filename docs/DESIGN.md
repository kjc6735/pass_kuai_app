# pass_kuai — 디자인 시스템 (미니멀)

방향: **깔끔/미니멀**. 흰 배경, 한자 타이포가 주인공, 색은 성조에만.

## 컬러
| 용도 | 값 |
|------|----|
| 배경 | `#FFFFFF` / 카드 `#FAFAFA` |
| 본문 텍스트 | `#1A1A1A` |
| 보조 텍스트 | `#9CA3AF` |
| 구분선 | `#EFEFEF` |
| 주요 버튼(잉크) | `#111111` (텍스트 흰색) |

### 성조 색 (유일한 컬러 포인트)
| 성조 | 색 |
|------|----|
| 1성 (─) | `#E5484D` 빨강 |
| 2성 (／) | `#30A46C` 초록 |
| 3성 (∨) | `#0D7DD6` 파랑 |
| 4성 (＼) | `#8E4EC6` 보라 |
| 경성 (·) | `#9CA3AF` 회색 |

## 타이포
- 한자 본문: 28–40px, 굵게. 단어 카드 한자: 32px.
- 병음: 한자 위 12–14px, 회색 또는 성조색.
- 번역(한국어): 15–16px, 보조 텍스트색.
- 폰트: Noto Sans SC(한자) + 시스템 한글.

## 간격/모양
- 화면 좌우 패딩 20px.
- 카드: 라운드 16px, 그림자 없음(테두리 `#EFEFEF` 또는 옅은 배경).
- 버튼: 라운드 12px, 높이 52px.
- 하단 탭 3개: 분석 / 단어장 / 학습.

## 원칙
1. 한 화면에 색은 성조 외 최대 1개(잉크 버튼).
2. 그림자보다 여백·테두리로 구분.
3. 정보 밀도 높은 화면일수록 더 비워서 균형.
